# v1.1.1 驗證紀錄

日期：2026-11-28。遊戲相容對象為 Windows Steam v1.0.4.3／Build 26937150。使用原有遊戲引擎、隔離工作副本與獨立 APPDATA，測試不加入玩家的正式房間。

## 正常擊球與六種特效

確認舊版有兩個問題：正常練習相機下，原環形線寬約 0.92～1.5 px，起始形狀容易藏進球／角色；連線加入方與遠端自由練習的部分事件則不經 Ball.struck。

- 17 項原生事件回歸通過，包含真正 Player._do_touch → Ball.hit → Ball.struck，以及練習、本機、房主和預測配置。
- 網路擊球接收、自由練習接收、預測回音、重複與舊序號、跨局、非啟用場景及重播排除，使用隔離的已解碼接收事件驗證。此處不冒稱真實 Steam 多人對局。
- 六款程序視效的 30 項渲染、世界、有限縮放、深度測試及自動釋放檢查通過。正常遊玩相機下另檢視實際觸球結果。

## F8 與預覽

- 移除常駐入口後，F8、Esc、GUI 關閉仍正常。
- 六款預覽使用獨立 World3D，不觸發真實球或角色動作；預覽的 Esc／F8 只關閉預覽，保留設定面板。
- 35 項實際渲染／GUI／隔離檢查通過，包含 640×360 版面與六種效果的可見像素。

## 全員統計與同步

- 統計保存在模組自己的狀態，不寫入原遊戲的官方 _stats。任意玩家的可靠魚躍碰撞可提供記錄；電腦角色同樣列入。
- 模型檢查包含不同肇事者、關閉個人顯示仍記錄與同步、500 ms 發送節流、2 秒最新狀態更新、僅數字封包、未收到資料顯示無資料、錯誤資料拒絕、序號和比賽代次檢查。
- 22 項模型檢查通過；實際 1 對 1～6 對 6 結算共 54 項欄位、數字與對齊檢查通過，原官方統計保持不變。結算時間停止時仍能更新。
- 原生同一 Main 呼叫「再玩一次」後計數清零；原遊戲並不更換 generation，因此同步序號保持遞增，避免加入方拒收新一局的零次快照。
- 兩個獨立程序以真實 localhost ENet，沿用與遊戲相同的 authority／call_remote／reliable 下行事件 API 測試：房主兩位玩家為 2／1 次，加入方接收到相同的 2／1 次；兩端正常退出。
- localhost 測試驗證序列化與傳送，不等同於已在兩個 Steam 帳號之間完成實際房間測試。真實同房顯示仍需要房主與觀看方都安裝新版。

## 完整模組整合

在 v1.0.4.3 遊戲副本執行的 27 項整合檢查全部通過：設定與預覽載入、兩個統計模組正確串接、舊個人列停用、沒有常駐入口、既有繁中與身份保護、原生設定／自由練習，以及維持較低的漢化節點處理量。

原生遊戲複本的測試退出行為與 v1.1.0 紀錄相同；原版不載入模組的相同 SceneTree.quit() 流程也可出現 Godot 資源釋放錯誤。本次未更動遊戲引擎。
