# v1.2.1 效能與相容性驗證

日期：2026-11-28。遊戲 Windows Steam v1.0.4.3／Build 26937150。

## 實際修正

- 隱藏的結算表、HUD 與跨 SubViewport 介面不再逐幀翻譯或套用字體；顯示時立即補譯，遊戲時間停止時也適用。
- 可見動態文字重用快取；名稱、聊天、輸入框與情境譯法的保護保留。
- 原生遊戲每幀重設自由練習的 20 個 Label3D 標示。舊版又改回中文，造成文字模型反覆重建。現在以引擎原生顯示翻譯呈現相同中文，保留原始文字，避免這個往返。
- 操作提示同樣只對明確的動作標籤使用原生翻譯；其他介面仍沿用情境處理。六種隊伍人數的完整譯文由既有模板產生。
- 球跡頭部重用固定網格、逐幀更新變換；歷史幾何改用索引緩衝批次提交，保留八種外觀、30 Hz 歷史更新、12 條與 48 點上限。
- 擊打特效改以實際時間清理生命週期；修正結算時間停止時，預覽持續生成而舊特效不消失的累積問題。

## 原生遊戲量測

同一台 RTX 3060 Laptop GPU 測試機、D3D12、1280×720、關閉 VSync 與 FPS 上限。主選單先暖機 8 秒，練習場 3 秒，另等待 240 個影格，再各取樣約 4 秒。測試以隔離遊戲副本與 APPDATA 執行，未變更正式遊戲的畫質或 FPS 設定。

先測舊版，再測新版，最後反向重測舊版。以下使用反向重測的舊版結果，排除第一輪冷載入造成的主選單異常；數字為此機器與場景的觀察結果，不是所有玩家的 FPS 保證。

| 項目 | v1.2.0 | v1.2.1 |
| --- | ---: | ---: |
| 主選單漢化 CPU／幀 | 1.232 ms | 0.434 ms |
| 自由練習漢化 CPU／幀 | 1.596 ms | 0.474 ms |
| 主選單平均 FPS | 287 | 364 |
| 自由練習平均 FPS | 112 | 274 |
| 自由練習影格時間中位數 | 9.38 ms | 3.15 ms |
| 自由練習影格時間 p95 | 12.78 ms | 5.99 ms |

主選單漢化 CPU 成本降低約 65%，自由練習約 70%。同機原版自由練習約 316 FPS，仍有場景與載入波動；本次處理的是已確認的模組額外負擔。

另一次診斷記錄中，80 個影格內，20 個練習標示各發生 77 次中文回寫。新版原生顯示翻譯的完整量測中，切入練習後 `text_writes` 維持 28，不再隨這些標示逐幀增加。實際畫面已確認操作提示及場地標示仍為繁中。

## 球跡與特效

12 顆球、附魔主題、0.9 秒殘留、強度 0.85、受控 240 Hz 時鐘；每版暖機 240 次，量測 720 次。這是 headless 模組 CPU 測試，不是整個遊戲的 FPS。

| 項目 | v1.2.0 | v1.2.1 |
| --- | ---: | ---: |
| 球跡 CPU 平均／次 | 816 µs | 339 µs |
| 球跡 CPU p95／次 | 5,443 µs | 2,193 µs |

平均降低約 58.5%。八種主題逐三角形頂點、顏色與頭部重用檢查 32／32 通過；保留原有視覺。受控 240 Hz 慢球停止再啟動 5／5 通過。

完整真遊戲球跡回歸 30／30 通過，包含原生召球、擊球後物理飛行、已呈現的球身中心、同世界繪製、停止／凍球／暫停／瞬移／換場清理、預覽隔離與數量上限。

擊打生命週期檢查 7／7 通過：零時間倍率下連續生成 12 次後，舊版留下 12 個特效，新版最多同時 5 個且閒置後歸零。八款樣式的 Mesh／子節點結構一致，沒有刪除粒子或幾何。

## 翻譯與範圍

漢化核心 28／28 檢查通過，包含字體設定、姓名／輸入保護、可見文字即時回寫、隱藏介面、零時間倍率下跨 Viewport 顯示與節點離場清理。

原生翻譯 36／36 檢查通過：操作標籤與練習標示的原文保持、連續影格不回寫、姓名禁譯、大小寫例外的手動後備，以及 Label3D 呈現邊界與同字體字級的手動中文參考相符。離開對應介面情境時會還原原翻譯模式；重新進入及改為玩家名稱情境也已驗證。

正式來源的原生遊戲整合 36／36 通過：主選單、原版設定、F8 設定、整組特效預覽、字體調整、名稱／輸入保護、自由練習標示與提示、趣味統計連線及設定還原均正常。原生翻譯標籤以其實際譯文與畫面驗證，不把保留的英文原值誤判為漏譯。

安裝／移除回歸 11／11、v1.2.0 升級與缺檔拒裝 3／3 通過；原始備份、其他設定與原版 EXE／PCK 保持不變。

本次沒有新增網路資料類型或變更玩法數值。實際 Steam 跨帳號多人連線與共用 World3D 的多攝影機分割畫面，仍以既有驗證範圍為準。

隔離遊戲副本結束時仍可能出現原版既有的原生資源釋放訊息；量測與功能報告於退出前保存，未把該行為計為模組效能改進。
