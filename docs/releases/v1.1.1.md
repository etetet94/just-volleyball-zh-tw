# v1.1.1｜繁中介面、六種擊打特效與全員撲倒統計

適用於 **just volleyball Windows Steam 版 v1.0.4.3／Build 26937150**。第一次安裝與舊版升級都下載本頁的 `JustVolleyball-zhTW-v1.1.1.zip`，不需要 Python 或 Godot 編輯器。

## 安裝／從舊版升級

1. 先透過 Steam 安裝遊戲，並完全退出遊戲。
2. 下載下方 **JustVolleyball-zhTW-v1.1.1.zip**，完整解壓縮到一般可寫入的資料夾；不要直接在 ZIP 內執行。
3. 按兩下 **Install.cmd**，看到「繁體中文模組已安裝」後即可照常從 Steam 啟動。
4. 遊戲中按 **F8** 開啟模組設定，調整中文字體、強度與效果；按「預覽特效」可先確認，Esc 返回設定。

已安裝本專案舊版的朋友直接執行新版 Install.cmd 即可升級，不必先移除；個人模組選項會保留。若遇到權限不足，確認已完整解壓縮，再右鍵以系統管理員身分執行 Install.cmd。找不到遊戲時，安裝包 README.md 有手動指定路徑的方法。

## 本版內容

- 保留 1,620 組繁中翻譯與玩法指南，加入清晰字重、100–120% 字級與文字對比選項，減少漢化的重複掃描。
- **光環、星芒、漫畫、火焰、冰雪、雷電**六種擊打效果，可切換、調整強度及獨立預覽。
- 修正正常遊玩時特效過小、過細與容易被角色遮住的問題，補上線上權威擊球及遠端自由練習事件，避免預測回音重複播放。
- **移除常駐 F8 按鈕**，只保留鍵盤快捷鍵。
- 結算每位玩家都有**「撲倒」次數**，包含電腦角色；只在實際倒地與碰撞來源可靠吻合時記錄，每場重設。

## 和朋友一起看統計

**房主與要看到新增欄位的朋友，都必須安裝 v1.1.1 或相容的後續版本。**

房主統計全員次數，透過遊戲既有房間事件同步數字。房主沒有新版模組時，加入方顯示「—」而非零次；沒有安裝模組的玩家不會自動出現新增介面。擊打效果為各自的本機顯示，朋友也可自行選擇風格。

統計不會寫入官方戰績，也不會自動傳送聊天訊息；不修改球路、體力或碰撞數值。已完成正常擊球、1 對 1～6 對 6 結算與本機雙端 ENet 同步驗證；尚未以兩個 Steam 帳號完成實際房間端到端測試。[完整驗證紀錄](https://github.com/etetet94/just-volleyball-zh-tw/blob/main/docs/VALIDATION-v1.1.1.md)。
