## 安裝／從舊版升級

1. 完全退出遊戲。
2. 下載本頁附件 **JustVolleyball-zhTW-v1.3.0.zip**，完整解壓縮到一般可寫入的資料夾。請勿直接在 ZIP 內執行，也不必下載 GitHub 自動提供的 Source code。
3. 按兩下 **Install.cmd**，看到安裝完成後，照常從 Steam 啟動遊戲。
4. 遊戲中按 **F8** 選擇主題；確認「殺球強化軌跡」與「華麗得分記分板」開啟。Esc 關閉面板。

已有舊版可直接執行新版 Install.cmd 升級，不必先移除。既有字體、特效主題、球跡設定與存檔會保留，新功能預設開啟。安裝包不需要 Python 或 Godot 編輯器。

若找不到遊戲，依安裝包 README.md 手動指定遊戲目錄。權限不足時，確認已完整解壓縮，再以系統管理員身分執行 Install.cmd。保留解壓縮資料夾，之後完全退出遊戲並執行 **Uninstall.cmd** 即可移除模組。

## 這版更新

- 真正殺球時加入飽和能量尾翼、亮芯、雙層氣浪環與螺旋流光；八套主題與擊打特效成套配對。
- **保留原生辨識敵我球權的軌跡**。新球跡沿已飛過的位置顯示，不修改球路、碰撞或玩法數值。
- 強攻得分、鐵壁攔網、打手出界、發球得分等加入斜切大字、事件徽記與兩隊比分演出；只在遊戲確認得分後播放。
- 犯規會另外寫明原因，區分發球踩線、越中線、標竿外過網、四次觸球與非法攻擊發球等。有足夠原生事件證據時，才細分觸碰標竿、觸白帶或觸網後未過網；合法擦網不會被標為犯規。
- 修正擊球瞬間的原生停頓被誤當成停球，造成球飛出後過早失去強化軌跡的問題。
- 保留 1,620 組繁中翻譯、指南、字體設定與全員撲倒統計。特效與得分演出是各自的本機顯示；朋友要看到新增畫面，也需要安裝模組。

## 效能與 F8 設定

「特效細節」預設 **自動調節**：持續負載較高時先減少裝飾光絲，保留主要能量輪廓與原生球權提示；可自行改為完整細節或精簡裝飾。

沿用前版漢化快取，球跡重建分散到不同影格，得分演出結束就停止更新。新增畫面仍有渲染成本，無法保證所有設備完全零掉幀。可在 F8 單獨關閉殺球強化、球跡或得分演出，並調整強度與殘留時間。
