# v1.3.0 視覺與相容性驗證

日期：2026-11-28。Windows Steam 遊戲 v1.0.4.3／Build 26937150。

## 殺球軌跡

只觀察原生擊球與網路既有事件，真正的 SPIKE（TouchKind 3）才啟用強化。軌跡沿已呈現的球身中心取樣，不預測未來路線。原生敵我球權軌跡未被隱藏、關閉或改色，新增的雙翼在中央保留辨識空間。

八種主題使用飽和外層、深色輪廓、細亮芯、雙層氣浪環與螺旋流光。一般接球、下一次觸球、落地、召回、換場與重播都有清理或取消強化的處理。

- 幾何與品質檢查 30／30：八主題、頂點與三角形界限、預建頭部、自動品質降級與恢復。
- 事件、序號與重建預算 31／31：新對局低序號、舊對局與重複事件、彈跳後不重啟、遠端與個人用球對應、每幀上傳上限與多球輪替。包含 300 ms 原生擊球停頓後真正移動仍能保留強化，以及未起飛超時、後續真正停止、凍球與舊世代停止事件。
- 隔離的原生遊戲使用真正跳躍、拋球與 Player._do_touch，確認 SPIKE 3、序號增加及過網；擊球後繼續使用原生物理。原生球跡的實例、顏色與繪製層有另外記錄。
- 最終 12 秒、1080p30 實機影片 47／47 檢查通過：一般接球對照三種殺球、空中實際移動時持續強化、落地立即取消、原生球跡可見與實例／繪製層保持、球頭跟隨及完整影片解碼。只有一個歷史點的暖機樣本不當作可繪製的球跡；飛行中已有可繪製歷史的樣本另行確認。

## 得分與犯規

透過 Rally.point 或加入方既有 rally_end 事件讀取已完成的判定，不改比分、判定或網路封包。原生七種非空失分原因均有對應，未知原因保留原文作為後備。

| 原生原因／證據 | 顯示含義 |
| --- | --- |
| foot fault | 發球端線踩線或越線 |
| line fault | 球員跨越中線進入對方場區 |
| outside the antenna | 標竿外過網；有同次原生 antenna_hit 才標觸碰標竿 |
| illegal attack on serve | 對發球作出遊戲禁止的攻擊、攔網或跳躍舉球 |
| four touches | 同隊觸球超過三次，沿用遊戲對攔網觸球的計算 |
| serve foul | 發球程序違規或未完成發球；依可確認的狀態補充原因 |
| ball out | 出界，或符合原生攔網證據時顯示打手出界 |
| 同次 net_hit、last_net_over、未再過網／觸球且球落回己方 | 依證據細分觸白帶後未過網或觸網後未過網 |

合法擦網不直接構成犯規。遠端資料不足時顯示伺服器提供的原因，避免猜測白帶或未過網。

原生得分／犯規、遠端原因、重複與舊對局事件、重播排除、預覽與零時間倍率清理的 44 項布林檢查通過。標竿與白帶的截圖使用隔離的原生判定情境。演出使用實際時間，1.65 秒後關閉更新；閒置時不逐幀繪製。F8 預覽明確標記預覽，不使用假的實戰比分。

## 效能邊界與實測

新增的畫面仍有渲染成本，不保證每台電腦都完全不掉 FPS。

- 保留 v1.2.1 的漢化快取、原生顯示翻譯與隱藏介面處理。
- 最多 12 條球跡，每條最多 48 個點；歷史取樣上限 30 Hz。
- 每幀最多重建兩條歷史網格，約 1.2 ms 軟預算並輪替；單次引擎上傳可能超出軟預算。球頭保持逐幀跟隨。
- 自動品質在持續較慢的影格下降低裝飾，負載恢復並穩定後才恢復細節；主體輪廓與原生球權提示保留。
- 頭部幾何可重用，得分演出重用節點與幾何，不新增全螢幕後製、即時光源或反覆閃屏。

同一台 RTX 3060 Laptop GPU、1280×720、OpenGL Compatibility、VSync 與 FPS 上限關閉，主選單暖機 8 秒、練習場 3 秒，再等待 240 幀，各取樣約 4 秒。兩版使用同一隔離資料夾與已完成首次教學的設定，關閉其他驗證程序後順序比較：

| 場景 | v1.2.1 平均 FPS | v1.3.0 平均 FPS |
| --- | ---: | ---: |
| 主選單 | 370.7 | 326.8 |
| 自由練習閒置 | 213.0 | 250.9 |
| 自由練習關閉特效 | 228.1 | 247.5 |

結果有正負波動，不能當成零下降保證或全面效能提升。主選單兩版同為 203 個繪製呼叫，新得分模組閒置時不處理影格。首次 D3D12 測量在引擎啟動階段退出，因此未把該次數字納入比較；實機特效另以原生 D3D12 錄製驗證。

12 球、附魔主題、0.9 秒殘留、受控 240 Hz 的極端 CPU 測試中，新版高細節的分散重建將 p95 從集中重建的約 9.8 ms 降到約 2.7 ms。這是同一新版實作在有／無預算時的 CPU 測試，不是整個遊戲的 FPS，也不與不同背景負載的舊版平均值比較。

原生遊戲整合 46／46：主選單、遊戲原版設定、F8 新選項、品質設定的保存與轉交、兩種預覽及關閉清理、玩家名稱／輸入保護、原生操作提示與練習場標示、趣味統計與字體刷新回歸。

本次未新增跨帳號實際 Steam 連線驗證；遠端路徑由既有事件及原生資源的隔離測試覆蓋。共用世界的分割畫面仍沿用原有相容性範圍。測試副本退出時可見的引擎資源釋放警告有保留，不列為 FPS 改善或模組通過的證據。
